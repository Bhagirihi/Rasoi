### How to read this report

- **Exact title duplicate** — same dish name, different IDs. Usually unintentional; pick one canonical row.
- **Core title family** — same dish after stripping marketing prefixes like "Quick", "Dhaba", "Rasoi". Many are **intentional SEO variants** from `marketing-ad-missing-batch.ts`.
- **Unintentional core duplicate** — same core title across non-marketing recipes (higher cleanup priority).
- **Same ingredient set** — identical ingredient lists; may still differ in steps/description.
- **Near title pair** — high (≥88%) or moderate (75–87%) word overlap between titles.
- **Near ingredient pair** — ≥90% ingredient overlap but not identical lists.
