CANVA WORKFLOW — OPTION A (Edit individual frames)
--------------------------------------------------
1. Create design 1290 × 2796
2. Upload 01-hero.png (or any frame)
3. Adjust text if needed — keep headlines under 7 words
4. Duplicate page 7 times for remaining frames
5. Replace image on each page with 02…08 PNGs
6. Download each page as PNG

CANVA WORKFLOW — OPTION B (Panoramic master)
-------------------------------------------
1. Create design 10320 × 2796 (or use canva-panoramic-full-res.png as base)
2. Upload canva-panoramic-full-res.png
3. Slice into 8 equal columns (each 1290px wide) using Canva crop or “Split”
4. Export 8 PNGs at 1290×2796
